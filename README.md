Banking Risk and Loan Portfolio Analysis
Project Overview
This project focuses on analyzing banking data to evaluate loan portfolio performance and identify potential banking risks using Power BI.

Objectives
Analyze loan portfolio performance. Understand loan distribution across different categories. Evaluate key banking risk indicators. Identify trends and patterns in loan data. Present meaningful insights through interactive dashboards.
Tools & Technologies: Microsoft Power BI, Power Query, DAX.

Key Performance Indicators (KPIs)
Total Loans: 149K
Total Loan Amount: 49bn
Default Loans: 37K
Default Rate: 24.6%
Average Credit Score: 699.79
Average Interest Rate: 4.03
Average Loan-to-Value (LTV): 72.99
Average Debt-to-Income (DTI): 37.94

Key Insights
The North region accounts for the highest total loan amount.
Medium-risk loans contribute the largest share of the loan portfolio.
The overall default rate is approximately 24.6%, exceeding the 20% target.
Customers in the 35–44 age group receive the highest loan amount.
Loan purpose P4 has the highest number of loans.
Lower credit scores are associated with higher default rates.
High-risk borrowers show a higher average Loan-to-Value (LTV) ratio.
LTV, income and DTI indicators are among the factors highlighted in the default risk analysis.

Conclusion

This project demonstrates the use of Power BI for analyzing banking data, monitoring loan portfolio performance, and presenting insights through interactive visualizations.
